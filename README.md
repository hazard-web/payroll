# Pulse Timer

Desktop check-in timer for People OS. This branch is **Electron only** — no frontend or backend.

Installers (UAT): https://github.com/hazard-web/payroll/releases/tag/pulse-timer-uat

```bash
npm start
```

Local bridge: `127.0.0.1:39217`. Check in from the People OS web app after the timer is running.
